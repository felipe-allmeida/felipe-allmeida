### 🛰️ Flagship — [pulse](https://github.com/felipe-allmeida/pulse)

A **live, real-time system embedded in a portfolio**: open the page and you see who else is online, a live world map of visitors, and the system's own public metrics — updating in real time. The "cool" surface is a thin client over a genuinely distributed backend, built as a production-grade engineering reference.

> **.NET 10 + SignalR** (Redis backplane) · **event-driven** with **RabbitMQ + EF transactional outbox** · **PostgreSQL** · **OpenTelemetry** · **React 19** · deployed via **Docker + Caddy + Terraform** (Hetzner) with **GitHub Actions** CI/CD. It even ships an AI assistant that answers recruiter questions from a curated profile.
>
> 🔗 Live demo — *coming soon at [felipealmeida.tech](https://felipealmeida.tech)* · [source &amp; architecture write-up](https://github.com/felipe-allmeida/pulse)
